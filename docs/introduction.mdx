Amperstand is a self-hosted read-it-later and research vault. You send it a link from your browser, your phone or a script; it saves the readable content as a markdown file on a machine you control and indexes it for search. Your notes app, your scripts and your AI agents read the same files through one HTTP API.

## What you can do

- **Capture from anywhere.** One click in Chrome, a link pasted into a Telegram chat, `amperstand capture <url>` in a terminal, or a POST from any script. Everything lands in the same vault.
- **Keep the content, not the bookmark.** Each capture is the full readable text with title, author and date in YAML frontmatter, as a plain markdown file. Open the folder in Obsidian, grep it, back it up. If you stop using the tool, the files stay.
- **Search it.** Keyword search works with no extra setup. With an OpenAI key you also get semantic and hybrid search, and chat over the vault.
- **Feed it to agents.** The vault is a corpus your agents query through the API, whether from a skill, a system prompt or a shell-out.
- **Follow sources.** Subscribe to RSS and Atom feeds and to a newsletter mailbox; new items are captured on a schedule.

## What it captures

| You send | What is saved |
| --- | --- |
| Article or blog post URL | Readable text with title, author and publication date. JavaScript-heavy pages are rendered before extraction. |
| YouTube URL | Title, channel, description and the transcript when captions exist, with optional Whisper transcription when they don't. |
| LinkedIn post URL | The post text and author. |
| X / Twitter URL | The post text and author. |
| RSS or Atom feed | Every new entry, captured as an article. |
| Newsletter email | The email body as markdown, pulled from a mailbox the server watches over IMAP. |
| Page HTML from the browser extension | The article extracted from the page as you saw it, including pages behind your own login. |

Extraction runs on the server. Clients only hand over a URL or the page HTML.

## How it fits together

One server, any number of clients, HTTP with an API key between them.

```
   CLI        Telegram bot     Chrome extension     your own client
    └──────────────┴──────────────────┴───────────────────┘
                              HTTP + API key
                          ┌─────────────────┐
                          │ amperstand-core │  markdown files + search index
                          └─────────────────┘
```

- **The server** (`amperstand-core`) is the only component that touches your data. It runs on any Linux machine you control, from a small VPS to a home server or your laptop. It stores the vault as markdown files plus a SQLite index, and it exposes the HTTP API.
- **Clients** are anything that speaks HTTP. The CLI, the Telegram bot and the Chrome extension are reference clients. A Discord bot, an iOS Shortcut or an n8n flow can do the same job through the API.

## What you need

- A Linux host with Python 3.10 or newer, or Docker.
- An OpenAI API key for semantic search, hybrid search, chat and audio transcription. Without it, capture and keyword search work and those features return `503`.
