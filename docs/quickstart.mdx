This page sets up the server. There's one canonical path: clone the repo on an Ubuntu host, run `bootstrap.sh`, install the CLI on your laptop, capture a URL.

If you've never deployed a server before, expand **Step 0** for the hand-held DigitalOcean walkthrough. Everyone else: jump straight to Step 1.

Prefer containers? Use the [Docker Compose install](/server-install-docker) instead — same destination, different host footprint.

## Read first: what depends on what

Most of Amperstand's features need third-party APIs you bring yourself. Be honest with yourself about the data flow before you deploy.

### OpenAI API — required for half of the features

| Feature | Model | Cost |
| --- | --- | --- |
| **Embeddings** (semantic + hybrid search) | `text-embedding-3-small` | ~$0.02 per 1,000 docs at capture time |
| **Hybrid-search rerank** (default behavior; deep-research skill leans on it) | `gpt-4o-mini` | ~$0.001 per query |
| **Chat-with-vault** (`/chat` — notebook UI) | `gpt-4o-mini` | ~$0.001 per chat turn |
| **LinkedIn video transcripts** (opt-in via `AMPERSTAND_AUDIO_TRANSCRIPTION=1`) | OpenAI Whisper | ~$0.006/min of audio |

**Without `OPENAI_API_KEY`:** capture + keyword search still work; semantic + hybrid + chat return `503`; LinkedIn videos are saved without a transcript.

**Privacy note.** Embedding sends doc bodies to OpenAI at capture time. Hybrid rerank sends queries + retrieved passages. If your corpus is confidential, set `OPENAI_API_KEY` to empty and live with keyword-only search. There's no local-model alternative built yet (Ollama / sentence-transformers on the roadmap; PRs welcome).

### Anysite API — required for LinkedIn, YouTube and Reddit

Cloud hosts are blocked by LinkedIn and YouTube and walled by Cloudflare-fronted sites. The server delegates those fetches to [Anysite](https://anysite.io): 1 credit per LinkedIn post, YouTube video or Reddit post, 10 for a browser-rendered article page. Set `ANYSITE_ACCESS_TOKEN` in the env file. Without it those captures fail; plain articles still work. Per-endpoint detail in [Configuration](/configuration#anysite).

## Step 0: Get an Ubuntu host (if you don't have one)

<AccordionGroup>
<Accordion title="Never deployed a server before? Expand this. ~20 min, then continue to Step 1.">

We'll use **DigitalOcean** because their $4 droplet is the reference target and their UI is friendly. Hetzner, Vultr, Linode, your home server — all work the same way once you're SSH'd in.

**You'll need:**
- A credit card (DigitalOcean: ~$4–6/mo, billed hourly; first-time accounts get $200 of credit)
- A terminal (macOS Terminal, Linux any terminal, Windows: PowerShell or WSL)

**0a. Generate an SSH key if you don't have one.** An SSH key is how your laptop proves "it's me" to the server, no passwords.

```bash
ls -la ~/.ssh/id_ed25519.pub
# If the file exists, you have a key — skip to 0b.
# Otherwise:
ssh-keygen -t ed25519 -C "your-email@example.com"
# Press Enter at every prompt to accept defaults.

# Print the public part — copy the whole `ssh-ed25519 ...` line:
cat ~/.ssh/id_ed25519.pub
```

**0b. Sign up for DigitalOcean.** Go to [digitalocean.com](https://www.digitalocean.com/) → Sign Up. Verify email, add a payment method.

**0c. Create the droplet.** Top-right → **Create** → **Droplets**.
- **Region**: pick one near you
- **OS**: Ubuntu, latest LTS
- **Plan**: Basic / Regular / **$4/mo** (1 GB RAM / 1 vCPU / 25 GB SSD)
- **Authentication**: **SSH Key** (not Password). Click "New SSH Key", paste the `ssh-ed25519 ...` you copied above, name it.
- **Create Droplet**.

Wait ~30s. The droplet's IP appears in your dashboard. Copy it — that's your `<your-server-ip>`.

**0d. SSH in:**

```bash
ssh root@<your-server-ip>
# Type `yes` when it asks about the host key. You should land at `root@...:~#`.
```

You're inside your server. Continue to Step 1.

</Accordion>
</AccordionGroup>

If you already have an Ubuntu 22.04+ host you can SSH into as root, you're at the same point. Continue.

## Step 1: Run the bootstrap

On the server:

```bash
git clone https://github.com/zkid18/amperstand-core /opt/amperstand/amperstand-core
cd /opt/amperstand/amperstand-core
sudo bash deploy/bootstrap.sh
```

This takes 3–5 minutes. The script is idempotent — safe to re-run.

**What it does on your host:** apt-installs Python + Caddy + ufw; creates an `amperstand` system user; generates `AMPERSTAND_API_KEY` and writes it to `/etc/amperstand/env` mode 0640; builds a venv at `/opt/amperstand/venv`; installs systemd units (`amperstand-server`, `amperstand-vault-watcher`, `amperstand-feed-sync.timer`, `amperstand-email-watch` disabled until configured); configures Caddy on `:80`; opens ports 22/80/443 in UFW; starts the server and waits for `/health`.

It writes to `/etc/`, `/opt/`, `/var/lib/` and opens firewall ports. Read it (~150 lines) before running on a host with other things on it.

When it finishes, it prints the new API key. **Copy it now** — treat it like a password.

<Tip>
If you missed the print, retrieve it: `grep '^AMPERSTAND_API_KEY=' /etc/amperstand/env | cut -d= -f2-`. For threat model + rotation details, see [Authentication](/api-reference/authentication).
</Tip>

## Step 2: Add the third-party keys

On the server:

```bash
sudo nano /etc/amperstand/env
```

Add the keys you need:

```ini
# For semantic + hybrid + chat + Whisper (see "what depends on what" above)
OPENAI_API_KEY=sk-...

# For LinkedIn, YouTube, Reddit, and walled-page capture
ANYSITE_ACCESS_TOKEN=...

# Opt-in to Whisper transcription of LinkedIn post videos
AMPERSTAND_AUDIO_TRANSCRIPTION=1
```

Save (`Ctrl-O`, `Enter`, `Ctrl-X`) and restart:

```bash
sudo systemctl restart amperstand-server
```

See [Configuration](/configuration) for every env var the server reads.

## Step 3: Verify it's running

From the server:

```bash
curl http://localhost/health
# {"status":"ok"}
```

From your laptop:

```bash
curl http://<your-server-ip>/health
```

Both should return `{"status":"ok"}`. If they don't: `sudo journalctl -u amperstand-server -n 50` on the server.

## Step 4: Install the CLI on your laptop

Type `exit` to leave the server. Back on your laptop:

```bash
pip install amperstand
```

Requires Python 3.10+.

## Step 5: Point the CLI at your server

```bash
# Save the key to a 0600 file (only you can read it)
echo "<paste the API key from Step 1>" > ~/.amperstand-api-key
chmod 600 ~/.amperstand-api-key

# Export it in your shell rc so new shells pick it up
echo 'export AMPERSTAND_API_KEY="$(cat ~/.amperstand-api-key | tr -d "\n")"' >> ~/.zshrc
source ~/.zshrc
# (Replace ~/.zshrc with ~/.bashrc if you're on bash.)

# Tell the CLI where the server is
amperstand vault backend set-server http://<your-server-ip> \
    --api-key-env AMPERSTAND_API_KEY
```

<Warning>
`--api-key-env AMPERSTAND_API_KEY` is the **name** of the env var, not the value. The CLI stores the name and reads the value at runtime — rotation stays cheap.
</Warning>

## Step 6: Capture your first URL

```bash
amperstand capture https://danluu.com/why-hardware-development-is-hard/
```

```
Saved: 01JK8XQ4... — Why hardware development is hard
  vault/2026/06/why-hardware-development-is-hard.md
```

🎉 Your vault is live.

## When things go wrong

<AccordionGroup>
<Accordion title='"Permission denied (publickey)" when I SSH in'>
DigitalOcean didn't get your SSH key added to the droplet. In the dashboard: Settings → Security → SSH Keys → add yours → then destroy and recreate the droplet with the key attached.
</Accordion>

<Accordion title="Bootstrap failed halfway">
Re-run it: `cd /opt/amperstand/amperstand-core && sudo bash deploy/bootstrap.sh`. Idempotent — picks up where it failed.
</Accordion>

<Accordion title="curl /health hangs">
Firewall might not have opened port 80, or Caddy didn't start. On the server:

```bash
sudo systemctl status amperstand-server
sudo systemctl status caddy
sudo ufw status
```

If Caddy isn't running: `sudo systemctl start caddy`. If UFW blocks 80: `sudo ufw allow 80`.
</Accordion>

<Accordion title='The CLI says "API key invalid"'>
Env var not set in the current shell, or you typed the key wrong:

```bash
echo $AMPERSTAND_API_KEY    # should print 64 hex chars
amperstand vault backend show
```

If empty: `source ~/.zshrc` (or open a new terminal).
</Accordion>

<Accordion title="DigitalOcean billing is more than I expected">
The $4 droplet bills hourly at ~$0.006/hr. Idle: ~$4/mo. **Powering off a droplet does NOT stop billing** — to actually stop charges, destroy it (Dashboard → droplet → Destroy).
</Accordion>
</AccordionGroup>

## Manual install (skip bootstrap)

If you don't want bootstrap touching your host, do it by hand:

```bash
git clone https://github.com/zkid18/amperstand-core /opt/amperstand/amperstand-core
cd /opt/amperstand/amperstand-core

python3 -m venv /opt/amperstand/venv
/opt/amperstand/venv/bin/pip install -e .

sudo mkdir -p /etc/amperstand
sudo tee /etc/amperstand/env <<EOF
AMPERSTAND_API_KEY=$(openssl rand -hex 32)
AMPERSTAND_DATA_DIR=/var/lib/amperstand/vault
EOF
sudo chmod 0640 /etc/amperstand/env

source /etc/amperstand/env
export AMPERSTAND_API_KEY AMPERSTAND_DATA_DIR
/opt/amperstand/venv/bin/amperstand-server --host 0.0.0.0 --port 8765
```

You'll then set up systemd + Caddy yourself — see [Deployment](/deployment).
