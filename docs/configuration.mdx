The server reads its configuration from environment variables (typically via `/etc/amperstand/env` in production, or `export` in your shell for local).

## Required

| Variable | What | Default |
| --- | --- | --- |
| `AMPERSTAND_API_KEY` | The API key every client must send | none — server refuses to start without it |
| `AMPERSTAND_DATA_DIR` | Vault root (markdown + sqlite live here) | `/var/lib/amperstand/vault` |

## Recommended

| Variable | What | Without it |
| --- | --- | --- |
| `OPENAI_API_KEY` | Embeddings, hybrid-search rerank, YouTube Whisper fallback | Semantic search returns 503; hybrid search degrades to FTS5-only; YouTube without captions = empty transcript |

`OPENAI_API_KEY` is technically optional, but if you're running the server you almost certainly want it. See [embedding setup](/quickstart#3-set-up-embeddings) in the quickstart.

## Tuning

| Variable | Default | What |
| --- | --- | --- |
| `AMPERSTAND_CAPTURE_WORKERS` | `1` | Concurrent async-capture workers |
| `AMPERSTAND_CAPTURE_JOB_TIMEOUT_S` | `120` | Per-job extraction timeout |
| `AMPERSTAND_CAPTURE_MAX_ATTEMPTS` | `3` | Attempts per capture before the job is `failed`; retries back off from 1 min to 1 h |
| `AMPERSTAND_CHAT_MODEL` | `gpt-4o-mini` | Model used by the chat API (`POST /chat`) |
| `AMPERSTAND_RERANK_MODEL` | `gpt-4o-mini` | Model used by hybrid-search rerank |
| `AMPERSTAND_RERANK_ENABLED` | `1` | Set to `0`/`false`/`no` to disable rerank globally |

Bumping `AMPERSTAND_CAPTURE_WORKERS` above 2–3 on a small droplet will trip the OOM-killer during a YouTube burst. Leave it at 1 unless you've sized for it.

## YouTube

| Variable | Default | What |
| --- | --- | --- |
| `AMPERSTAND_YOUTUBE_AUDIO_FALLBACK` | off | Set to `1` to let Whisper transcribe videos with no captions |
| `AMPERSTAND_YOUTUBE_AUDIO_MAX_SEC` | `3600` | Cap on audio-fallback length (avoids 4-hour podcasts eating your OpenAI bill) |

Audio fallback needs `OPENAI_API_KEY` *and* the `linkedin` extra installed (which bundles `faster-whisper`):

```bash
pip install "amperstand-core[linkedin]"
```

(The name is historical — the extra also covers Whisper for YouTube.)

## Outbound proxy (optional)

Some hosts block bots from YouTube / X / LinkedIn. If you have a residential proxy, set:

| Variable | What |
| --- | --- |
| `AMPERSTAND_PROXY_URL` | HTTP(S) proxy URL passed to yt-dlp and trafilatura |

## API surface + admin behavior

| Variable | Default | What |
| --- | --- | --- |
| `AMPERSTAND_HIDE_DOCS` | off (docs visible) | Set to `1` to hide `/openapi.json` / `/docs` / `/redoc`. The auth dep gates every endpoint regardless, so visible OpenAPI doesn't expose data — but if you don't want the schema discoverable at all, flip this. |
| `AMPERSTAND_ENV_FILE` | `/etc/amperstand/env` | Path the server reads at startup for the env file. Frozen at process start — runtime changes ignored (security). |
| `AMPERSTAND_ROTATE_MIN_INTERVAL_S` | `10` | Minimum seconds between successful `POST /admin/rotate-key` calls. Defends against a leaked-key attacker thrashing the env file. |
| `AMPERSTAND_ALLOW_HTTP_ROTATE` | off | Set to `1` to allow `POST /admin/rotate-key` over HTTP (no `X-Forwarded-Proto: https`). Dev only — production should be on TLS so the new key isn't visible to a MITM. |
| `AMPERSTAND_ADMIN_ORIGINS` | empty | Comma-separated list of allowed `Origin` headers for `/admin/*`. Empty = browser requests (with any `Origin`) are rejected unless they match. Non-browser requests (no `Origin` — curl, CLI, bot) pass through regardless. |
| `AMPERSTAND_UVICORN_WORKERS` | `1` | uvicorn worker process count. **Keep at 1** — `/admin/rotate-key` refuses with 503 when >1 because in-memory rotation only updates one worker's env. |

## Reading config from a file

On production, the systemd unit loads `/etc/amperstand/env` — same `KEY=VALUE` format as `.env` files, owned `root:amperstand` mode `0640`.

```ini
AMPERSTAND_API_KEY=...
AMPERSTAND_DATA_DIR=/var/lib/amperstand/vault
OPENAI_API_KEY=sk-...
AMPERSTAND_CAPTURE_WORKERS=2
```

`amperstand-admin` reads the same file (or env, falling back) so its outputs match what the server sees.

## Quick sanity check

```bash
amperstand-admin config show
```

Prints the resolved configuration (with secrets redacted) so you can confirm the server will see what you expect.
